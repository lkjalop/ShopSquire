## TDD and the meaning of green

A named gate is green when the intended assertions execute on the identified source and installation, the native command exits zero, required cases are not skipped and resource budgets hold. A blocked response may pass its safety contract while leaving the requested task unfinished.

New valid red controls cover privacy ownership/redaction, unreachable app cycles and browser collection changing the parent URL. An initial URL test used identical ports and passed; it was not defect proof. A first privacy export fixture hit native SQLAlchemy string handling before ownership assertions; the subsequent baseline run isolates the ownership failures. Missing Chromium, Git, a test path or a fixture is a prerequisite failure, never a passing gate. The preserved native logs and receipts distinguish these attempts.

Passing sets overlap and span several sources and profiles. There is **no defensible overall completion percentage**. Completion requires the named workflow outcomes and final-source gates above, not a sum of historical passes or retained conversational facts.
