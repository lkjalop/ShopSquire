# ShopSquire crash investigation and remaining roadmap

The 11 October crash followed an NVIDIA GPU failure and unsuccessful display recovery. CPU-only verification has resumed, but the platform is not fully green and the conditional commit gate remains open. GPU-backed endurance must wait for the host graphics investigation; passing simulated workflows does not certify the display driver, model quality or production readiness.

Microsoft defines [bugcheck 0x116](https://learn.microsoft.com/en-us/windows-hardware/drivers/debugger/bug-check-0x116---video-tdr-failure) as failed display timeout recovery. Its third argument records the last failed operation's status. `c000009a` is insufficient resources; it does not, by itself, prove exhaustion of ordinary RAM or VRAM. Driver defects, firmware, thermal/power issues and hardware remain possible underlying causes.

The local evidence is in `.artifacts/verification-2026-10-11/crash-investigation/windows-events.json`, `display-drivers.json` and `gpu-after-reboot.csv`. Windows reports the dump at `C:\Windows\Minidump\101126-19187-01.dmp`. Access to the dump and protected WER reports was denied, and no installed debugger was found, so there is no completed dump stack analysis. Do not upload the dump to a public analysis site.

The interrupted model-browser configuration explicitly used owned loopback port `11435`, with VLM/CV startup warming disabled. This does not supply temperature/VRAM telemetry at the crash or establish its underlying cause.

GPU/model testing remains paused. Review the [exact Lenovo model's support page](https://pcsupport.lenovo.com/au/en/products/laptops-and-netbooks/legion-series/legion-pro-7-16iax10h/83f5/downloads/driver-list) and Lenovo Vantage for applicable graphics/BIOS/VBIOS packages and their release notes. A particular firmware fix has not been verified for this unit. Obtain local administrator dump analysis and vendor diagnostics before treating a driver change as a confirmed cure. No firmware flash, driver uninstall, registry timeout extension or forced reboot was performed.
