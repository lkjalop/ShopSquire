# August 2026 assessment archive

The dated assessment, roadmap, diagnosis, and product-notes files committed with
this index are retained as design evidence. They are not runtime configuration,
release gates, or current proof by themselves.

Use the following authority order when statements conflict:

1. executable tests and certification artifacts from the referenced revision;
2. current runtime health and Decision Trace receipts;
3. the current phase/release-integrity status document;
4. dated assessment documents in this archive.

The documents may contain historical local-development examples such as
placeholder API-key names. They do not contain production credentials and must
not be copied into a deployed environment.

The product list in `2026-08-08 laptop-products-aug.txt` is retained as source
material, not as a sealed relevance corpus or a live price/availability feed.
