## Browser gate before further feature work

Use real APIs and a fresh database; fake supplier/payment effects remain enforced. Assert durable case versions, stock events, approval records and exact effect counts as well as visible text. Store source digest, runtime flags, traces and failed-request diagnostics for each run.

1. **Ordinary shopping:** new browser, authenticated tenant, university laptop under AUD 1,500; then change budget, quantity, deadline and product category. Verify useful candidates or a specific truthful explanation, with no inherited qualification from another subject.
2. **Memory:** interdependent messages, corrections, ambiguity, unrelated turn, reload, second tab and backend restart; different user/tenant cannot recall the first user's data. Test failed reset/forget and concurrent erase/write.
3. **Qualification:** conversation, suggested/selected scope and explicit consent, research, shelf and trace agreement. Expiry, revoked consent, changed configuration, conflict and model failure withdraw unsupported conclusions. Show fixture and live-research results separately.
4. **Availability:** an over-budget top pick with cross-store stock; accepted 30-unit request, 15-unit shortfall, concurrent second buyer, hold expiry, shipment, cancellation, inbound delivery, transfer and return. Balances reconcile after retries.
5. **Supplier and amendments:** independently approved fake enquiry, partial offer, substitution, duplicate, wrong sender, silence, expired quote; accept 30→40 and verify freight, MOQ, landed cost, deadline, reservations and obsolete approvals. Recheck shortfall immediately before dispatch.
6. **Approval and recovery:** same person/two credentials, wrong tenant/tier, revoked grant, changed payload, unknown committed spend, double-click, lost response and crash after provider acceptance. Check no committed transition hidden behind an error, duplicate send or false completion.
7. **Cart/bundles:** supported, incompatible and unknown accessories; explicit acceptance, quantity/price changes and permit expiry. Suggestions never silently mutate the cart.
8. **Operator surfaces:** authenticate from an empty profile, inventory/recovery/merchant/legacy admin pages, Grafana read queries, expired session, logout, keyboard navigation and visible error recovery.
9. **Search/security:** empty, denied, unavailable, cancelled and successful governed research; supplier/search/OCR/memory injection canaries. Count unauthorized effects and leakage, but also legitimate tasks incorrectly refused.
10. **Endurance:** reproduce the failing reload with request/resource/socket diagnostics. Compare Vite development serving with a built production preview to distinguish development-server/module-load behavior. Fix the cause before another timed run; preserve assertions. Then pass a defined 60-minute browser/API run, a separately bounded mixed-model/varied-image run, and finally eight hours. Thresholds cover correctness, latency, host memory, process RSS/handles and network errors.
